# Привіт, я Влад 👋

Роблю Telegram-ботів, Telegram Mini App, лендинги із заявками в Telegram і автоматизації, які працюють без власного сервера.

Понад 3 роки в технічній підтримці, тож думаю не лише про код, а й про те, як рішенням користуватимуться: зрозумілий інтерфейс, захист від помилок, інструкція для замовника.
